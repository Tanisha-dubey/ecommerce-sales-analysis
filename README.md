# E-commerce Sales Analysis

## Project Overview

This project analyzes e-commerce sales and profitability data using Python and Jupyter Notebook.

## Objectives

The analysis focuses on:

- Monthly sales analysis
- Sales by product category
- Sales by sub-category
- Monthly profit analysis
- Profit by category and sub-category
- Sales and profit by customer segment
- Sales-to-profit analysis

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset

The project uses the Superstore dataset containing information about orders, products, sales, profit, categories, customer segments, and other business attributes.

## Project Structure

- `ecommerce_sales_analysis.ipynb` — Jupyter Notebook containing the complete analysis
- `Sample - Superstore.csv` — Dataset used for the analysis
- `README.md` — Project documentation

## Key Analysis

The notebook explores sales and profitability trends across different months, categories, sub-categories, and customer segments.
